Jika izin mikrofon ditolak
  1. Tekan ikon pengaturan/izin situs di bilah alamat browser.
  2. Atur Microphone / Mikrofon menjadi Allow / Izinkan untuk alamat GitHub Pages ini.
  3. Jika tidak muncul, buka Pengaturan HP → Aplikasi → Chrome → Izin → Mikrofon.
  4. Kembali ke halaman ini, muat ulang bila perlu, lalu tekan Coba lagi.

Pengenalan suara browser mungkin memerlukan internet dan dukungannya bergantung pada browser/perangkat. Halaman ini tidak menyimpan rekaman atau API key.
